# TravelMate – Project Statement

## Introduction
TravelMate is a simple Python-based train and bus ticket booking system designed to make basic ticket management and booking easier.

## Purpose
The main purpose of this project is to manage train and bus details and allow passengers to book tickets according to their destination and seat availability.

## Main Features
- Add train and bus ticket details
- Edit existing ticket information
- Book train and bus tickets
- Store passenger details
- Check available seats
- Update seats after booking

## Technologies Used
This project is developed using **Python** and uses basic programming concepts such as lists, functions, loops, conditional statements, and user input.

## Conclusion
TravelMate is a beginner-friendly project created to demonstrate practical use of Python programming concepts through a simple ticket booking system.
