# TravelMate – Train and Bus Ticket Booking System

## Overview
TravelMate is a simple Python-based ticket booking system. It allows users to add and edit train/bus details and book tickets for passengers based on their destination.

## Features
- Add train and bus tickets
- Edit train and bus details
- Book train and bus tickets
- Enter passenger name and age
- Check available seats
- Automatically update remaining seats
- Simple menu-based interface

## Technologies Used
- Python
- Lists
- Functions
- Loops
- Conditional statements
- Visual Studio Code
